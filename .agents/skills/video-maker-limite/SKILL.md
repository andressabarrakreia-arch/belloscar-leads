# video-maker fica fora deste site

Repositório: [filipedeschamps/video-maker](https://github.com/filipedeschamps/video-maker).

É um tutorial de vídeo automatizado. Pede chaves de Algorithmia, Watson, Google Custom Search e YouTube, e publica conteúdo.

## Regras

- Não clone o repositório para dentro de `belloscar-leads`.
- Não crie pasta `credentials` nem grave API key no projeto.
- Não ligue a página de erros a upload no YouTube.
- O cruzamento de IDs continua na página Erros, com ECharts e D3.
