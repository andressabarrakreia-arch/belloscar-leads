# Cinematic Web Skill Evals Rubric

Score each response from 0 to 2 for each category.

## Art Direction

- 0: Starts coding generic animation with no concept.
- 1: Mentions mood or references but does not operationalize them.
- 2: Produces a brief with brand feeling, metaphor, asset strategy, composition, and non-goals.

## Motion System

- 0: Uses ad hoc durations and default easing.
- 1: Adds a few constants but does not use them consistently.
- 2: Creates or reuses tokens for eases, springs, durations, staggers, scroll, and reduced-motion substitutions.

## Choreography

- 0: Adds scattered triggers or vague animation.
- 1: Uses scroll animation but without labels or clear numbers.
- 2: Defines a timeline with pin range, scrub, labels, parallax ratios, and element tracks.

## WebGL And Assets

- 0: Adds heavy WebGL or placeholders without caveats.
- 1: Adds a scene but weakly handles assets or fallbacks.
- 2: Separates canvas architecture, names asset assumptions, clamps DPR, and provides fallback behavior.

## Post-Processing

- 0: Adds global effects indiscriminately.
- 1: Uses some restraint but lacks selection or tuning notes.
- 2: Uses selective effects, documents constants, and disables/simplifies effects where appropriate.

## Performance And Accessibility

- 0: Ignores performance and reduced motion.
- 1: Mentions them but leaves behavior incomplete.
- 2: Implements fallbacks, lazy loading, budgets, and verification steps.

## Delivery

- 0: Gives a vague summary.
- 1: Lists files changed but misses risks or verification.
- 2: Reports files changed, motion tokens, choreography numbers, asset assumptions, risks, reduced motion, and verification.
