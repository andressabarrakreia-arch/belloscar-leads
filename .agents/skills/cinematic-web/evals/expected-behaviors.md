# Expected Behaviors

The skill should make another agent act like a senior creative developer.

## It Should

- Ask for or infer a compact art-direction brief.
- Convert inspiration sites into transferable qualities.
- Create or reuse motion tokens before adding animation.
- Use one scroll timeline per story section.
- Use R3F only when depth, camera, material, or shader behavior is justified.
- Prefer selective post-processing.
- Name asset assumptions and production gaps.
- Provide reduced-motion fallbacks.
- Report verification steps and remaining risks.

## It Should Not

- Treat "cinematic" as permission for random parallax.
- Clone a famous site.
- Put the whole page in a client component without cause.
- Ship heavy WebGL without inspection or fallback.
- Use global bloom over text.
- Hide missing assets behind vague language.
