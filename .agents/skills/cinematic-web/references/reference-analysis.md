# Reference Analysis

Use this reference when a user mentions Huly, Linear, Vercel, Stripe, Basement Studio, Awwwards, or another inspirational site.

## Rule

Extract qualities. Do not clone layouts, copy assets, reproduce proprietary art direction, or imitate a brand so closely that the result feels like a knockoff.

## Analysis Format

```md
# Reference Analysis

## Sources
- URL or screenshot:
- User-stated goal:

## Transferable qualities
- Composition:
- Motion pacing:
- Depth/lighting:
- Typography density:
- Interaction feel:
- Color behavior:

## Non-transferable details
- Brand-specific assets:
- Proprietary illustrations:
- Distinctive layout signatures:
- Copy or messaging:

## New direction
- Brand feeling:
- Visual metaphor:
- Differentiator:
```

## Safe Inspiration Moves

- Convert "looks like Huly" into "rich illustrated system scene with depth and controlled ambient motion."
- Convert "like Linear" into "restrained hierarchy, precise timing, dense product clarity."
- Convert "like Stripe" into "luminous gradients, crisp surfaces, technical confidence."
- Convert "like Vercel" into "minimal composition, strong contrast, performance-first restraint."
- Convert "like Basement Studio" into "bold art direction, immersive visual rhythm, strong editorial sequencing."

## Red Flags

- Reusing another site's exact composition.
- Matching a proprietary illustration style too closely.
- Treating a famous brand's palette as the user's palette.
- Shipping a generic "inspired by" page with no product-specific idea.
- Naming references in public copy unless the user explicitly wants comparative copy.

## Output Language

Prefer:

```text
I used the reference for motion density, depth cues, and scroll pacing, then changed the visual metaphor, palette, layout, and asset language for this product.
```

Avoid:

```text
I recreated the Huly hero.
```
