# Final Review Checklist

## Creative

- [ ] Art direction brief exists or quick-build exception is documented.
- [ ] References were analyzed without copying.
- [ ] Asset assumptions are explicit.

## Motion

- [ ] Shared motion tokens are used.
- [ ] Choreography has numbers and labels.
- [ ] Reduced-motion behavior is implemented.

## Performance

- [ ] DPR is clamped for WebGL.
- [ ] Heavy dependencies are lazy-loaded.
- [ ] Assets fit declared budgets or exceptions are documented.
- [ ] Debug controls are removed from production.

## Accessibility

- [ ] Keyboard focus is intact.
- [ ] Pinned sections do not trap users.
- [ ] Text remains readable and real HTML where needed.

## Verification

- [ ] Desktop viewport checked.
- [ ] Mobile viewport checked.
- [ ] Reduced-motion mode checked.
- [ ] Build or tests run.
