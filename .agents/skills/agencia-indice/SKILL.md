# Agência no índice

Referência de ofício: [agency-agents](https://github.com/msitarzewski/agency-agents). São personas em texto, não um pacote npm.

- Não clone o repositório dentro de `belloscar-leads`.
- O mapa mostra o que as planilhas têm. DDD vira lugar. Cidade que não está na base não é inventada.
- Tipo de veículo só entra quando o nome do cliente existe na negociação. O texto da tela diz isso.
- A página de erros continua a tabela de IDs. O mapa mora no índice.
