# Quadro do cruzamento

A rede de pontos do sigma saiu da página Erros. O demonstrativo é o quadro das cinco planilhas.

- Cada faixa conta os IDs com presença `nao`. A barra usa `scaleX`, um transform.
- O clique na faixa recorta os IDs. O clique no número preenche a busca da tabela.
- Mostre no máximo 16 IDs. O restante fica na tabela.
- sigma e graphology podem continuar instalados. Esta tela não desenha o grafo.
