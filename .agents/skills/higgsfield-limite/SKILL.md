# Higgsfield não entra neste painel

Repositório: [higgsfield-ai/higgsfield](https://github.com/higgsfield-ai/higgsfield).

É orquestração de GPU para treinar modelos enormes. O índice não treina modelo e não tem cluster.

- Não rode `pip install higgsfield` neste projeto.
- Os números do mapa saem das planilhas importadas.
